# 调度模型芯片

先在设置 → 模型里为默认模型和至少一个角色（例如编码）各自保存一个模型 id。准备一个工作区。

## AG-1 显示当前模型

### 步骤

1. 新建一条对话，角色留默认 Agent。
2. 看作曲栏左侧的芯片。

### 预期

- 文案是 `Agent · <默认模型 id>`，例如 `Agent · grok-4.6`。
- 悬停标题含「当前调度模型」和这个模型 id。
- 没有配置任何模型、也没有已登录的 Grok 会话时，芯片只显示 `Agent`，不编造模型名。

## AG-2 打开菜单并切换角色

### 步骤

1. 点击该芯片。
2. 在「选择角色」里点「编码」（或另一个已配置模型的角色）。
3. 刷新页面。

### 预期

- 菜单打开，列出默认 Agent、各角色和流水线，每项旁边是它实际会用的模型 id。
- 点选后菜单关闭，芯片变成 `Agent · <该角色的模型 id>`。
- 刷新后仍是这个模型，不是回到写死的 `Agent`。

## AG-3 切回默认 Agent

### 步骤

1. 再次打开菜单。
2. 点「无（默认 Agent）」。

### 预期

- 芯片回到 `Agent · <默认模型 id>`。
- 若之前选过流水线，流水线也被清掉，下一轮按默认 Agent 跑。

## AG-4 不能切换的时候

### 步骤

1. 在没有选中任何对话时点击芯片。
2. 打开一条对话，发送消息，在状态为运行中时再点击芯片。

### 预期

- 没有对话时出现「请先选择对话」，菜单不打开。
- 运行中、恢复中或已暂停时出现「运行中无法切换角色」，菜单不打开，当前模型不变。
