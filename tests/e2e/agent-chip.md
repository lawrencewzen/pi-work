# 调度模型芯片

先在设置 → 模型里为默认模型和至少一个角色（例如编码）各自保存一个模型 id。准备一个工作区。

## AG-1 显示当前模型

### 步骤

1. 新建一条对话，角色留默认 Agent。
2. 看作曲栏左侧的芯片。

### 预期

- 文案是 `Agent · <默认模型 id>`，例如 `Agent · grok-4.6`。
- 悬停标题含「当前调度模型」和这个模型 id。
- 没有配置任何模型、也没有已登录的 Grok 会话时，芯片只显示 `Agent`，不编造模型名。

## AG-2 打开菜单并切换角色

### 步骤

1. 点击该芯片。
2. 在「选择角色」里点「编码」（或另一个已配置模型的角色）。
3. 刷新页面。

### 预期

- 菜单打开，列出默认 Agent 和各角色，每项旁边是它实际会用的模型 id。没有流水线分组。
- 点选后菜单关闭，芯片变成 `<角色名> · <该角色的模型 id>`，例如 `编码 · grok-build`。不再只显示模型名。
- 侧栏这条对话下的角色同时变成「编码」，不用刷新页面。
- 刷新后仍是这个角色和模型，不是回到写死的 `Agent`。

## AG-3 切回默认 Agent

### 步骤

1. 再次打开菜单。
2. 点「无（默认 Agent）」。

### 预期

- 芯片回到 `Agent · <默认模型 id>`。
- 侧栏这条对话下的主 Agent 立刻显示「主 Agent」（英文 Main agent），不用刷新页面。不再停在「编码」。名称框里的角色名仍可以是「默认」。
- 下一轮按默认 Agent 跑。

## AG-4 草稿可以选，运行中不能选

### 步骤

1. 还没有任何工作区时，点击作曲栏的 Agent 芯片。
2. 创建一个工作区，新建一条对话，先不要发送。点击芯片，在菜单里选一个角色。
3. 发送第一条消息。
4. 在状态为运行中、恢复中或已暂停时再点击芯片。

### 预期

- 完全没有工作区时提示「请先选择或创建一个工作区」，菜单不打开。
- 草稿对话（还没发第一条消息）时菜单可以打开。选中的角色记在草稿上，芯片马上显示这个选择。
- 第一次发送会创建这条对话，并把草稿里的角色写成它的调度目标。侧栏这条对话和芯片都显示该角色。
- 运行中、恢复中或已暂停时提示「运行中无法切换角色」，菜单不打开，当前模型不变。
