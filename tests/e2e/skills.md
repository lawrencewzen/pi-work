# Skills

设置 → Skills。需要可用模型。

## SK-1 新建 Skill

### 步骤

1. 打开设置，进入 Skills。
2. 点击「新建 Skill」。
3. 名称填 `口令`，简介填 `只在口令检查时使用`，说明填下面这一段后创建：

   当用户发送「口令检查」时，只回复一行 `PING-SKILL-947`，不要加别的文字。其他问题不要使用本 Skill。

### 预期

- 对话框关闭。
- 网格里出现卡片「口令」，简介可见，来源为本地导入，开关为开。

## SK-2 开关保持

### 步骤

1. 关掉「口令」的开关。
2. 关闭设置，刷新页面，再打开 Skills。
3. 再把「口令」打开。

### 预期

- 刷新后开关仍是关。
- 再次打开后开关为开。
- 「Commit messages」和「Review notes」仍在，且可以各自开关。

## SK-3 启用的 Skill 改变回复

### 步骤

1. 确认「口令」为开。
2. 新建对话，发送 `口令检查`，等到状态为完成。
3. 关掉「口令」，再新建一条对话，发送同样的 `口令检查`，等到完成。

### 预期

- 开关为开的那条：主 Agent 会按需调用 `skill` 工具加载该技能，回复包含 `PING-SKILL-947`，并且没有展开成长段说明。
- 开关为关的那条：清单里没有「口令」，`skill` 工具也读不到它，回复不包含 `PING-SKILL-947`。

## SK-4 删除自己建的 Skill

### 步骤

1. 打开设置 → Skills。
2. 看「Commit messages」和「Review notes」卡片。
3. 在 SK-1 建的「口令」卡片上点击「删除」。
4. 在页面中央的确认层里点「取消」。再打开一次，点遮罩或按 Esc。
5. 打开设置 → 通用，语言选 English，回到 Skills，再点 Delete。看完确认层后点 Cancel。
6. 切回中文。再点「删除」，在确认层里点「删除」。
7. 关闭设置，刷新页面，再打开 Skills。

### 预期

- 「Commit messages」和「Review notes」没有「删除」按钮。
- 「口令」有「删除」。点击后出现页面内确认层，盖在设置之上。这不是浏览器原生确认框。
- 中文时标题是「确认删除」，正文是「删除 Skill「口令」？」。按钮是「取消」和「删除」。确认按钮是危险样式：淡红底、删除色文字和边框。取消按钮是普通按钮。
- 点「取消」、遮罩或 Esc 后确认层关闭，设置还在，「口令」卡片还在。
- 在确认层点「删除」后卡片消失，并提示「已删除」。
- 英文时标题是 `Confirm delete`，正文是 `Delete skill “口令”?`，按钮是 Cancel 和 Delete。Delete 仍是危险样式。点 Cancel 不删除。
- 刷新后「口令」不再出现。两个内置 Skill 还在。
