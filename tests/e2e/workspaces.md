# 工作区与 Git 导入

左栏「工作区 & 对话」旁的 `+` 打开新建工作区。本地目录必须位于对话框提示的允许根目录之下。

## WS-1 本地目录

### 步骤

1. 在允许的根目录下准备一个空文件夹，里面放一个 `hello.txt`，内容是 `hello-ws`。
2. 打开新建工作区，停在「本地目录」。
3. 填写名称 `本地样本` 和该文件夹路径，点击创建。

### 预期

- 左栏出现「本地样本」。
- 右栏「文件」里能看到 `hello.txt`，预览内容是 `hello-ws`。

## WS-2 拒绝非法 Git 地址

### 步骤

1. 再打开新建工作区，切到「Git 导入」。
2. 名称填 `坏仓库`，地址留空，点击创建。
3. 地址改为 `file:///tmp/repo.git`，再点击创建。
4. 地址改为 `not-a-url`，再点击创建。

### 预期

- 空地址时对话框不关闭，错误是「请填写 Git 仓库地址」。
- `file://` 和普通字符串都提示「仅支持 https/ssh 的 Git 地址」。
- 左栏不出现名为「坏仓库」的工作区。

## WS-3 导入可克隆的仓库

### 步骤

1. 打开新建工作区 → Git 导入。
2. 名称填 `远端样本`。
3. 地址填一台运行 pi-work 的机器能够克隆的 `https://` 或 `ssh://` / `git@host:path` 仓库。分支可留空。
4. 点击创建，等待克隆结束。

### 预期

- 按钮在克隆时不可重复提交。
- 成功后左栏出现「远端样本」。
- 「文件」页能看到仓库里的文件，而不是空目录。
- 若这台机器访问不了该 Git 主机，本条记阻塞，并写下克隆错误原文。WS-2 仍须通过。
