# 对话

需要可用模型。先有一个工作区和一条对话。

## CH-1 左右气泡

### 步骤

1. 在输入框发送 `这是用户的一句短话。`
2. 等到助手回复出现，状态为完成。

### 预期

- 用户那句在右侧，助手回复在左侧。
- 刷新页面后两句都还在，左右关系不变。

## CH-2 Markdown

### 步骤

1. 在同一条或新的对话里发送：

   请只用 Markdown 回复，并包含：一个二级标题「计划」，一个加粗的词 README，以及一个代码块，代码块里只有 `console.log(1)`。

2. 等到完成。

### 预期

- 助手气泡里能看到标题「计划」、加粗的 README，以及一块等宽代码，内容含 `console.log(1)`。
- 这些是排好的标题、粗体和代码块，不是原样露出的 `#`、`**` 或围栏符号。

## CH-3 回复上方的模型标签

### 步骤

1. 用演示模型（faux）发一轮，等到完成。
2. 看主对话里助手回复上方的模型标签。

### 预期

- 标签文字是这条回复实际用的模型名（演示模型为 `faux-1`），不以「·」开头。
- 默认角色时标签前没有发送者小字，因此也没有「·」。
- 同一对话里中途换过模型时，前后回复各显示各自的模型名。
