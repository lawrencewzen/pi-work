# Agent

设置 → Agent，紧挨在「模型」后面。左侧是搜索和分组（主 Agent、子 Agent · 预设、子 Agent · 自定义），右侧是编辑区，底部是保存条。标识不显示，也不让填写。

默认界面是中文。模型下拉需要至少一个可用的 API 来源（例如 DeepSeek）才能选到非默认模型；没有来源时，把选模型那一条记为阻塞。本文件新建的对象不要改内置「功能交付」和「演示」；自定义子 Agent 测完按删除用例清掉。

出厂提示词在 `roles/*.json`。启动时会把没改过的旧英文内置提示词换成这份出厂稿。

## AG-1 新建中文名子 Agent

### 步骤

1. 打开设置 → Agent，点「＋ 新建子 Agent」。
2. 「从哪里开始」保持「空白」。
3. 名称填 `文档助手`，什么时候用填 `整理仓库里的说明文档`，提示词填 `只整理文档，不改代码。`。不要填写标识。
4. 点击「保存」。

### 预期

- 页面上没有标识输入框，保存请求里也没有 id。
- 出现提示「已保存」。列表「子 Agent · 自定义」里出现「文档助手」。
- 工具只有「读取文件」开着，「修改文件」「运行命令」「插件工具」是关的。

## AG-2 编辑后刷新仍在

### 步骤

1. 打开「文档助手」，把提示词改成 `只整理文档，不改代码。回复先写结论。`。
2. 点击「保存」。
3. 刷新页面，再打开设置 → Agent →「文档助手」。

### 预期

- 保存条在改字之后提示有未保存的改动。
- 刷新后名称、说明和提示词仍是改过的内容。

## AG-3 复制为新的子 Agent

### 步骤

1. 打开「文档助手」，点「复制为新的子 Agent」。
2. 把名称改成 `文档副本`，点击「保存」。

### 预期

- 进入新建，名称和提示词带着刚才那份。
- 保存后列表里同时有「文档助手」和「文档副本」，两边是不同的 Agent。

## AG-4 主 Agent

### 步骤

1. 在左侧点「主 Agent」。

### 预期

- 列表和编辑区标题是「主 Agent」。名称框里仍是它的名字（出厂是「默认」），可以改。
- 可以改名称、模型、提示词、工具和 Skills。
- 没有「什么时候用」。
- 没有「预设子 Agent」标签，也没有「删除这个 Agent」。有「恢复默认」。

## AG-5 预设子 Agent 恢复默认

### 步骤

1. 打开「编码」。确认有「预设子 Agent」标签，没有删除按钮。
2. 在提示词末尾加一行 `临时改动 WF`，点「保存」。
3. 点「恢复默认」，在确认层里确认。

### 预期

- 改过的提示词旁有「已改动，和预设版本不同」。
- 确认层说明模型选择保持不变。
- 恢复后提示词回到出厂稿，能看到「交回主 Agent」和「编码角色」，没有 `临时改动 WF`。刷新后仍是这份。

## AG-6 出厂提示词写明职责和交回主 Agent

### 步骤

1. 依次打开「规划」「编码」「测试」「审计」，看提示词。

### 预期

- 四处都能看到「职责」「输入」「输出」和「交回主 Agent」。
- 四处都写着自己是被主 Agent 派活的角色。

## AG-7 从预设复制

### 步骤

1. 点「＋ 新建子 Agent」。
2. 在「从哪里开始」里点复制「规划」。
3. 名称填 `规划稿`，在提示词末尾加一行 `验收时写日期`，点「保存」。

### 预期

- 点「规划」后，提示词里已有「交回主 Agent」和「规划角色」。
- 保存后出现「规划稿」，没有「预设子 Agent」标签。
- 内置「规划」还在，并且仍有预设标签。

## AG-9 被对话引用时不能删除，解除后可以删

### 步骤

1. 新建一条对话，角色选「复核」。
2. 再在 Agent 页删除「复核」。
3. 把这条对话改回默认 Agent 后，再删一次「复核」。
4. 刷新。

### 预期

- 对话还在用它时，提示「已有对话在使用这个 Agent」，「复核」还在。
- 解除引用后出现「已删除」，刷新后不再出现。
- 预设子 Agent 始终没有删除按钮。

## AG-10 子 Agent 选用 DeepSeek

需要一个可用的 DeepSeek（或其他非默认）来源，并且已经启用了要选的模型。

### 步骤

1. 打开「编码」的模型下拉。
2. 选 DeepSeek 的 `deepseek-chat`（或该来源里任一已启用模型）。
3. 点「保存」，然后看 `GET /api/settings` 的 `models`。

### 预期

- 下拉按来源分组，可搜索。第一项是「跟随默认 · 默认实际模型」。不可用来源整组置灰。最后一项是「去「模型」页添加…」。
- 保存后 `models` 里该子 Agent 的值是 `{ sourceId, model }`，source 不是只剩 default。
- 刷新后下拉仍是刚才选的模型。
- 页面上没有手填模型名的输入框。

## AG-11 Skills

### 步骤

1. 先在 Skills 页启用一个名字好认的 Skill，例如「检索笔记」。
2. 打开「编码」。Skills 一行是全选，并标着「跟随全局」。
3. 点「选择…」，在弹出列表里搜索「检索笔记」，点「清空」，再勾上「检索笔记」，点「完成」，然后「保存」。
4. 看 `GET /api/roles` 里编码的 `skills`。

### 预期

- 弹出列表只列全局已启用的 Skill，能搜索。
- 没改过时不写死名单（跟随全局）。
- 保存后 `skills` 是只含刚才勾选的那个 id 的数组。说明和插件工具开关没有被清掉。

## AG-12 关闭插件工具

### 步骤

1. 打开一个还在跟随全局 Skills 的预设，例如「规划」。
2. 关掉「插件工具」，点「保存」。
3. 看 `GET /api/roles` 里这个角色。

### 预期

- `pluginTools` 为 `false`。
- `skills` 仍然缺省（不是被重置成空数组），说明和提示词保持原样。

## AG-13 模型页只留默认模型

### 步骤

1. 打开设置 → 模型。
2. 点「各个 Agent 单独用什么模型，去 Agent 页设置」里的「Agent 页」。

### 预期

- 只有「默认模型」一行，绑定的是 `settings.models.default`。
- 没有「角色模型」整块，也没有第二个角色下拉。
- 点击后切到 Agent 页。
- 设置导航里没有「流程」。

### 步骤

1. 打开 Agent 页，把编辑区滚到「选择…」靠近弹窗底部。
2. 点「选择…」。

### 预期

- 下面放不下时向上弹，不被内容区裁掉。

## AG-16 英文没有漏翻

### 步骤

1. 设置 → 通用，语言改为 English。
2. 打开 Agent 页、模型下拉和新建子 Agent。
3. 改回中文。

### 预期

- 分组、字段、保存条、确认层都是英文。预设标签是 “Built-in sub-agent”。
- 改回中文后恢复中文。

## AG-17 旧库里的内置提示词会升级

本条用一份还保存着旧英文内置提示词的数据库。新库里的规划、编码、测试、审计本来就是中文出厂稿，打开后能看到「交回主 Agent」即可，不必为了本条去改回英文。

### 步骤

1. 用那份旧库启动 pi-work（重启一次即可，升级在启动时完成）。
2. 打开设置 → Agent，看「规划」「编码」「测试」「审计」的提示词。
3. 若其中某个是你保存过的改稿，对比重启前后的内容。

### 预期

- 没改过的内置角色不再是旧的短英文提示词，而是当前出厂稿：能看到「职责」「交回主 Agent」，以及对应的「规划角色 / 编码角色 / 测试角色 / 审计角色」。
- 你保存过的改稿还在，没有被出厂稿覆盖。

## AG-18 侧栏出现前台子 Agent，点开能看消息

需要 `PI_WORK_KERNEL=durable`。主 Agent 派出一个前台子 Agent（`delegate`）。视口 1440×900，再看一次 1000×760。

### 步骤

1. 新建对话并发送一条会派出前台子 Agent 的消息。
2. 等侧栏这条对话下面出现该子 Agent。
3. 点击这一行。
4. 点「返回主对话」。
5. 设置 → 通用，语言改为 English，再改回中文。

### 预期

- 子 Agent 和主 Agent 平铺在同一对话下：状态点、名称、进度或最近一句。主 Agent 显示「主 Agent」（英文 Main agent），没有额外标记。
- 点开后，助手消息的署名是这个子 Agent 自己的名字，例如「侦察」。
- 状态会随运行更新，不用刷新页面。
- 点开后中间是只读消息，气泡和工具行样式与主对话相同。顶部是「子 Agent · 名称 · 状态」，旁边是「返回主对话」。还在运行时，消息会自己更新。
- 返回后回到主对话，输入框可以继续用。
- 英文时顶部是 “Sub-agent · …”，按钮是 “Back to main chat”。改回中文后恢复。
- 1000×760 时中间对话区至少 420px，右侧 Diff 栏不超过 340px。暂停、继续、终止只留图标（仍有 title 和 aria-label）。Agent 芯片和上下文用量保持一行，超长用省略号。侧栏和顶部说明不重叠、不溢出屏幕。

## AG-19 后台子 Agent 有低调标记

需要 `PI_WORK_KERNEL=durable`。主 Agent 用后台方式派一个子 Agent（`subagent` spawn）。

### 步骤

1. 在同一条或另一条对话里派出后台子 Agent。
2. 看侧栏里它的那一行。

### 预期

- 名称旁边有小字「后台」，和前台子 Agent 分得开。
- 英文是 “Background”。
- 它也有状态点，以及进度或最近一句。
