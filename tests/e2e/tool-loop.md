# 工具连呼与单步上限

需要可用模型，以及一个可写的本地工作区。默认连续相同调用 3 次后会拦住，每个流水线步骤最多大约 25 次工具调用。

## TL-1 相同工具不会无限制重复

### 步骤

1. 新建对话，角色选「审计」。
2. 发送：`用 ls 看一下仓库根目录，然后用一句话说明看到了什么。不要对同一个目录反复调用 ls。`
3. 等到状态变为「完成」。数一数对话里 `ls` 工具行。

### 预期

- 状态是「完成」，不是一直停在「运行中」。
- 不会出现几十次参数相同的 `ls`。
- 若同一个工具带着相同参数连续出现了 3 次，紧接着能看到「停止调用工具」，并且后面有助手的文字回复，而不是继续空转。

## TL-2 流水线在工具很多时仍能完成

### 步骤

1. 新建对话，角色 / 流水线选「功能交付 (规划 → 编码 → 测试 → 审计)」。
2. 发送：`用一句话说明当前仓库是做什么的。按流水线走完规划、编码、测试、审计。不要重复调用同一个工具。`
3. 等到状态变为「完成」。

### 预期

- 状态是「完成」。
- 侧栏能看到规划、编码、测试、审计都走过，而不是停在某一步反复调用工具。
- 若某一步的工具调用很多，对话里会出现「工具调用已达上限」，这一步就此结束，后面的角色仍会继续。
