# 角色与流水线

设置 → 流程。默认界面是中文。先准备一个工作区。跑功能交付的那条需要可用模型；没有模型时只把那一条记为阻塞。

本文件新建的对象使用标识 `reviewer`、`review` 和 `note-planner`。测完按删除用例清掉，不要改内置的「功能交付」和「演示」。

规划、编码、测试、审计的出厂提示词在 `roles/*.json`。启动时会把没改过的旧英文内置提示词换成这份出厂稿。若你改过其中某个提示词，测 WF-12 之前先对那个角色做一次「恢复默认提示词」并保存。

## WF-1 新建角色

### 步骤

1. 打开设置，进入流程，确认分段在「角色」。
2. 点击「新建角色」。
3. 标识填 `reviewer`，名称填 `复核`，系统提示词填 `只做复核，不改代码。`
4. 允许的工具保持 `read`、`ls`、`grep`，模型留空。
5. 点击「保存」。

### 预期

- 出现提示「已保存」，回到角色列表。
- 列表里有卡片「复核」，标识是 `reviewer`，工具芯片是 `read`、`ls`、`grep`。

## WF-2 编辑角色

### 步骤

1. 在「复核」卡片上点击「编辑」。
2. 把系统提示词改成 `只做复核，不改代码。回复先写结论。`
3. 点击「保存」。
4. 再次打开「复核」。

### 预期

- 标识输入框是 `reviewer`，并且不能修改。
- 再次打开后，系统提示词仍是改过的那一句。

## WF-3 新建流水线

### 步骤

1. 切到「流水线」，点击「新建流水线」。
2. 标识填 `review`，名称填 `复核流程`。
3. 第 1 步角色选「编码」，输入选「用户原文」。
4. 点击「添加步骤」。第 2 步角色选「复核」，输入选「上一步输出」。
5. 点击「保存」。

### 预期

- 出现提示「已保存」，回到流水线列表。
- 卡片标题是「复核流程」，标识是 `review`，步骤链是「编码 → 复核」。

## WF-4 编辑流水线

### 步骤

1. 在「复核流程」卡片上点击「编辑」。
2. 把名称改成 `复核检查`。
3. 点击「保存」，再打开这张卡片。

### 预期

- 标识输入框是 `review`，并且不能修改。
- 列表标题变为「复核检查」，步骤链仍是「编码 → 复核」。

## WF-5 占用中的角色不能删除

### 步骤

1. 切回「角色」。
2. 在「复核」卡片上点击「删除」。页面中央出现确认层，不是浏览器原生确认框。正文是「删除角色「复核」？」，确认按钮是危险样式的「删除」。点「删除」。

### 预期

- 确认层标题是「确认删除」，按钮是「取消」和「删除」。确认按钮是淡红底、删除色文字和边框。
- 出现提示「该角色正在被流水线使用：复核检查」。
- 「复核」卡片还在。确认层已关闭。

## WF-6 删除流水线

### 步骤

1. 切到「流水线」。
2. 在「复核检查」上点击「删除」。确认层正文是「删除流水线「复核检查」？」，确认按钮是危险样式的「删除」。点「删除」。

### 预期

- 出现提示「已删除」。
- 列表里不再有「复核检查」。内置的「功能交付」和「演示」还在。

## WF-7 删除已不再被使用的角色

### 步骤

1. 切回「角色」。
2. 在「复核」上点击「删除」，在确认层里点「取消」。
3. 再点「删除」，在确认层里点「删除」。
4. 关闭设置，刷新页面，再打开流程 → 角色。

### 预期

- 点「取消」后确认层关闭，「复核」卡片还在。
- 确认删除后出现提示「已删除」。
- 刷新后「复核」不再出现。规划、编码、测试、审计、默认仍在。

## WF-8 默认角色保留

### 步骤

1. 在角色列表里看「默认」卡片。

### 预期

- 卡片上是「默认角色保留」，没有「删除」按钮。

## WF-9 新建对话可选功能交付

### 步骤

1. 关闭设置。
2. 点击新建对话，打开「角色 / 流水线」下拉。

### 预期

- 流水线分组里有「功能交付 (规划 → 编码 → 测试 → 审计)」。
- 同一分组里有「演示 (编码 → 测试 → 审计)」。

## WF-10 运行功能交付

需要可用模型。没有已登录的 Grok 会话，也没有已保存的 API Key 时，把本条记为阻塞。

### 步骤

1. 新建对话，标题填 `功能交付验收`，角色 / 流水线选「功能交付 (规划 → 编码 → 测试 → 审计)」，然后创建。
2. 发送：`用一句话说明当前仓库是做什么的。按流水线走完规划、编码、测试、审计。`
3. 等到这条对话的状态变为「完成」。

### 预期

- 侧栏这条对话下列出「规划」「编码」「测试」「审计」四行，彼此平级，没有「主」这一层。
- 对话里能看到交接「规划 → 编码」「编码 → 测试」「测试 → 审计」。
- 助手回复分别标着规划、编码、测试、审计，而不是全程都标成 Agent。

## WF-11 内置角色有「默认」标记

### 步骤

1. 打开设置 → 流程 → 角色。
2. 看规划、编码、测试、审计四张卡片，再看「默认」卡片。

### 预期

- 规划、编码、测试、审计各有一个「默认」标记。
- 「默认」卡片没有这个标记，仍是「默认角色保留」。

## WF-12 出厂提示词写明职责和交接

### 步骤

1. 打开「规划」，看系统提示词。
2. 返回，再打开「编码」「测试」「审计」，各看系统提示词。

### 预期

- 四处都能看到「职责」「输入」「输出」和「## 交接」。
- 规划的交接写着「角色：规划」，编码是「角色：编码」，测试是「角色：测试」，审计是「角色：审计」。

## WF-13 直接使用内置角色

### 步骤

1. 在角色列表点击「新建角色」。
2. 在「直接使用」里点「规划」。

### 预期

- 提示「已有内置角色「规划」，可在流水线里直接选用」。
- 回到角色列表，没有多出一张卡片。规划仍在，且仍有「默认」标记。

## WF-14 从出厂提示词改一个新角色

### 步骤

1. 点击「新建角色」。
2. 在「从提示词改」里点「规划」。
3. 标识填 `note-planner`，名称填 `规划稿`。在提示词末尾加一行 `验收时写日期`。
4. 点击「保存」。

### 预期

- 点「规划」后，提示词里已有「## 交接」和「角色：规划」，标识是空的。
- 保存后出现卡片「规划稿」，没有「默认」标记。
- 内置「规划」还在，并且仍有「默认」标记。

## WF-15 恢复默认提示词

### 步骤

1. 打开内置「规划」，在系统提示词末尾加一行 `临时改动 WF`。
2. 点击「保存」。回到角色列表，在「规划」卡片上点击「展开」。
3. 再次打开「规划」，点击「恢复默认提示词」，再点击「保存」。
4. 再打开一次「规划」，看编辑框里的全文；回到列表后再点一次「展开」。

### 预期

- 卡片上的提示词默认大约三行，并有「展开」。点「展开」后能看到全文，包括 `临时改动 WF`。编辑框里本来就是完整提示词，不只有这三行。
- 编辑内置角色时有「恢复默认提示词」。
- 恢复并保存后，编辑框和展开后的卡片里都没有 `临时改动 WF`，仍有「## 交接」和「角色：规划」。
- 再次打开时还是这一份，没有 `临时改动 WF`。

## WF-16 新建流水线时加入内置角色

### 步骤

1. 切到流水线，点击「新建流水线」。
2. 在「内置角色」里依次点「规划」和「编码」。不要先新建角色。

### 预期

- 能看到规划、编码、测试、审计四个按钮。
- 点「规划」后，第一步是规划，输入是「用户原文」。
- 再点「编码」后，第二步是编码，输入是「上一步输出」。不需要先新建这两个角色。

## WF-17 旧库里的内置提示词会升级

本条用一份还保存着旧英文内置提示词的数据库。新库里的规划、编码、测试、审计本来就是中文出厂稿，打开后能看到「## 交接」即可，不必为了本条去改回英文。

### 步骤

1. 用那份旧库启动 pi-work（重启一次即可，升级在启动时完成）。
2. 打开设置 → 流程 → 角色，点「展开」看「规划」，再看「编码」「测试」「审计」。
3. 若其中某个角色的提示词是你保存过的改稿，对比重启前后的内容。

### 预期

- 没改过的内置角色不再是旧的短英文提示词，而是当前出厂稿：能看到「职责」「## 交接」，以及对应的「角色：规划 / 编码 / 测试 / 审计」。
- 你保存过的改稿还在，没有被出厂稿覆盖。
