# 流水线

设置 → 流程。这一页只保留流水线的列表和编辑。角色（主 Agent / 子 Agent）的新建、编辑、恢复默认和删除在 [agents.md](agents.md)。

默认界面是中文。先准备一个工作区。跑功能交付的那条需要可用模型；没有模型时只把那一条记为阻塞。

本文件新建的流水线使用标识 `review`。步骤里的「复核」来自 Agent 页建好的子 Agent。测完按删除用例清掉，不要改内置的「功能交付」和「演示」。

## WF-3 新建流水线

### 步骤

1. 在 Agent 页先有一个名为「复核」的子 Agent（见 agents.md）。
2. 打开设置 → 流程。页面上没有角色分段，也没有角色卡片。
3. 点击「新建流水线」。
4. 标识填 `review`，名称填 `复核流程`。
5. 第 1 步角色选「编码」，输入选「用户原文」。
6. 点击「添加步骤」。第 2 步角色选「复核」，输入选「上一步输出」。
7. 点击「保存」。

### 预期

- 出现提示「已保存」，回到流水线列表。
- 卡片标题是「复核流程」，标识是 `review`，步骤链是「编码 → 复核」。
- 角色下拉里能看到全部子 Agent，包括刚建的「复核」。没有手填模型的输入框。

## WF-4 编辑流水线

### 步骤

1. 在「复核流程」卡片上点击「编辑」。
2. 把名称改成 `复核检查`。
3. 点击「保存」，再打开这张卡片。

### 预期

- 标识输入框是 `review`，并且不能修改。
- 列表标题变为「复核检查」，步骤链仍是「编码 → 复核」。

## WF-6 删除流水线

### 步骤

1. 在「复核检查」上点击「删除」。确认层正文是「删除流水线「复核检查」？」，确认按钮是危险样式的「删除」。点「删除」。

### 预期

- 出现提示「已删除」。
- 列表里不再有「复核检查」。内置的「功能交付」和「演示」还在。
- 页面上仍然没有角色卡片。

## WF-9 新建对话可选功能交付

### 步骤

1. 关闭设置。
2. 点击新建对话，打开「角色 / 流水线」下拉。

### 预期

- 流水线分组里有「功能交付 (规划 → 编码 → 测试 → 审计)」。
- 同一分组里有「演示 (编码 → 测试 → 审计)」。

## WF-10 运行功能交付

需要可用模型。没有已登录的 Grok 会话，也没有已保存的 API Key 时，把本条记为阻塞。

### 步骤

1. 新建对话，标题填 `功能交付验收`，角色 / 流水线选「功能交付 (规划 → 编码 → 测试 → 审计)」，然后创建。
2. 发送：`用一句话说明当前仓库是做什么的。按流水线走完规划、编码、测试、审计。`
3. 等到这条对话的状态变为「完成」。

### 预期

- 侧栏这条对话下列出「规划」「编码」「测试」「审计」四行，彼此平级，没有「主」这一层。
- 对话里能看到交接「规划 → 编码」「编码 → 测试」「测试 → 审计」。
- 助手回复分别标着规划、编码、测试、审计，而不是全程都标成 Agent。

## WF-16 新建流水线时加入内置角色

### 步骤

1. 打开设置 → 流程，点击「新建流水线」。
2. 在「内置角色」里依次点「规划」和「编码」。不要先去 Agent 页新建。

### 预期

- 能看到规划、编码、测试、审计四个按钮。
- 点「规划」后，第一步是规划，输入是「用户原文」。
- 再点「编码」后，第二步是编码，输入是「上一步输出」。不需要先新建这两个角色。
