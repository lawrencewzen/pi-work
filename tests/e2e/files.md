# 写文件与右侧三页

需要可用模型，以及一个可写的本地工作区。

## FL-1 写入并在 Diff 中看见

### 步骤

1. 新建对话，发送：`在工作区创建 notes/today.md，正文只有两行：第一行是「今日」，第二行是「QA-FILE-1」。不要改其他文件。`
2. 等到完成。
3. 看右侧 Diff。点击变更列表里的 `notes/today.md`。

### 预期

- 对话里有一次写文件的工具行，路径含 `notes/today.md`。
- 状态是「完成」，不是「失败」。状态栏不出现 `E_LLM terminated`。
- Diff 页能看到该文件，新增行里有「今日」和 `QA-FILE-1`。
- 磁盘上的工作区文件内容与预览一致。
- 若写完文件后模型连接中断，对话里会出现「已按完成的工具结果结束本步」，状态仍是「完成」。

## FL-2 文件页

### 步骤

1. 点击右侧「文件」。
2. 在树里点开 `notes/today.md`。

### 预期

- 树里有 `notes` 和 `today.md`。
- 预览正文含 `QA-FILE-1`。
- 不显示其他工作区的文件。

## FL-3 Markdown 编辑后仍在

### 步骤

1. 仍选中 `notes/today.md`，点击右上角「编辑」。
2. 在 Markdown 编辑器末尾加上一行 `QA-EDIT-2`。
3. 点击保存。
4. 刷新页面，再从文件树打开该文件。

### 预期

- 保存后编辑器仍显示 `QA-EDIT-2`。
- 刷新后文件内容能看到 `QA-EDIT-2`。
- Diff 对比的是基线和磁盘上的当前文件，新增行里能看到 `QA-EDIT-2`，不只是模型当初写入的那两行。
- 工作区磁盘上的 `notes/today.md` 也含这一行。

## FL-4 工具结果到达时文件树已更新

停在右侧「文件」。不要刷新页面，不要切换对话或工作区。需要可用模型，以及一个可写的本地工作区。

### 步骤

1. 点击右侧「文件」，等树出现。空工作区会显示「此工作区还没有文件」。
2. 新建对话，发送：`在工作区创建 live/qa-file-live.txt，正文只有 QA-LIVE-1。不要改其他文件。`
3. 对话里一出现写文件工具结果（路径含 `live/qa-file-live.txt`），立刻看文件树。先不要等状态变成「完成」。
4. 等这一轮状态变成「完成」。
5. 仍停在「文件」。再发送：`只用 bash，在工作区创建 live/qa-file-bash.txt，内容只有 QA-LIVE-BASH。不要调用 write 或 edit。`
6. bash 工具结果一出现就看文件树，然后再等这一步或这一轮变成「完成」。
7. 点开 `qa-file-live.txt`。切到 Diff，再切回「文件」。

### 预期

- 写文件工具结果出现时，树里已经有 `live/` 和 `qa-file-live.txt`。这时状态可以仍是「运行中」。
- 状态变成「完成」后，这两个名字仍在树里。
- bash 工具结果出现后，树里有 `qa-file-bash.txt`。本步或本轮完成时它也在。
- 预览正文含 `QA-LIVE-1`。磁盘上两个文件的内容分别是 `QA-LIVE-1` 和 `QA-LIVE-BASH`。
- 从 Diff 回到「文件」后，树里仍是这两个文件，不是打开页签时的旧列表。
- 流水线同样如此。测试步用 write、edit 或 bash 落下的文件（例如 `test_pipeline_confirmation.py`、`test_minimal_hello.py`）在该工具结果到达时、以及该步完成时就出现在树里，不必等到整条流水线结束。

## FL-5 无实际变更不进 Diff 列表

### 步骤

1. 接 FL-1。确认 Diff 变更列表里有 `notes/today.md`，并且新增或删除计数不是 +0 −0。
2. 点右上角「编辑」，把正文全部删掉，使文件回到基线。新建文件的基线是空内容。
3. 保存，再点右侧 Diff。

### 预期

- 变更列表里不再出现 `notes/today.md`。内容和基线相同（+0 −0）的文件不列出，徽标计数也不含它。
- 该文件仍是当前选中项时，Diff 区域显示「无变更」，不出现空白的「原始基线 / 工作副本」两列。

## FL-6 长文件名省略

### 步骤

1. 新建对话，发送：`在工作区创建 test_pipeline_confirmation.py，正文只有一行 print("ok")。不要改其他文件。`
2. 等到完成。点右侧「文件」。
3. 在左侧文件列表里找到 `test_pipeline_confirmation.py`，把鼠标停在文件名上。

### 预期

- 文件名在列宽内以省略号截断，不溢出到预览区，也不把列表撑出横向滚动。
- 悬停时提示（title）是完整文件名 `test_pipeline_confirmation.py`。
