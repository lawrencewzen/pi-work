# 写文件与右侧三页

需要可用模型，以及一个可写的本地工作区。

## FL-1 写入并在 Diff 中看见

### 步骤

1. 新建对话，发送：`在工作区创建 notes/today.md，正文只有两行：第一行是「今日」，第二行是「QA-FILE-1」。不要改其他文件。`
2. 等到完成。
3. 看右侧 Diff。点击变更列表里的 `notes/today.md`。

### 预期

- 对话里有一次写文件的工具行，路径含 `notes/today.md`。
- 状态是「完成」，不是「失败」。状态栏不出现 `E_LLM terminated`。
- Diff 页能看到该文件，新增行里有「今日」和 `QA-FILE-1`。
- 磁盘上的工作区文件内容与预览一致。
- 若写完文件后模型连接中断，对话里会出现「已按完成的工具结果结束本步」，状态仍是「完成」。

## FL-2 文件页

### 步骤

1. 点击右侧「文件」。
2. 在树里点开 `notes/today.md`。

### 预期

- 树里有 `notes` 和 `today.md`。
- 预览正文含 `QA-FILE-1`。
- 不显示其他工作区的文件。

## FL-3 Markdown 编辑后仍在

### 步骤

1. 仍选中 `notes/today.md`，点击右上角「编辑」。
2. 在 Markdown 编辑器末尾加上一行 `QA-EDIT-2`。
3. 点击保存。
4. 刷新页面，再从文件树打开该文件。

### 预期

- 保存后编辑器仍显示 `QA-EDIT-2`。
- 刷新后文件内容能看到 `QA-EDIT-2`。
- Diff 对比的是基线和磁盘上的当前文件，新增行里能看到 `QA-EDIT-2`，不只是模型当初写入的那两行。
- 工作区磁盘上的 `notes/today.md` 也含这一行。

## FL-4 无实际变更不进 Diff 列表

### 步骤

1. 接 FL-1。确认 Diff 变更列表里有 `notes/today.md`，并且新增或删除计数不是 +0 −0。
2. 点右上角「编辑」，把正文全部删掉，使文件回到基线。新建文件的基线是空内容。
3. 保存，再点右侧 Diff。

### 预期

- 变更列表里不再出现 `notes/today.md`。内容和基线相同（+0 −0）的文件不列出，徽标计数也不含它。
- 该文件仍是当前选中项时，Diff 区域显示「无变更」，不出现空白的「原始基线 / 工作副本」两列。

## FL-5 长文件名省略

### 步骤

1. 新建对话，发送：`在工作区创建 test_pipeline_confirmation.py，正文只有一行 print("ok")。不要改其他文件。`
2. 等到完成。点右侧「文件」。
3. 在左侧文件列表里找到 `test_pipeline_confirmation.py`，把鼠标停在文件名上。

### 预期

- 文件名在列宽内以省略号截断，不溢出到预览区，也不把列表撑出横向滚动。
- 悬停时提示（title）是完整文件名 `test_pipeline_confirmation.py`。
